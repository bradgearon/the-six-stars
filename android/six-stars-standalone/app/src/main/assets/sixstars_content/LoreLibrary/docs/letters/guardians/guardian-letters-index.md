# Guardian Letters Index

Guardian-facing letters are split across `sage-cats/`, `prophetic-endgame/`, and `fragments-and-variants/` because many of them are authored by sage cats but addressed to Leviathan, Bahamut/Behemoth, or the wider guardian class.

Use this index when designing letter-return cutscenes.
