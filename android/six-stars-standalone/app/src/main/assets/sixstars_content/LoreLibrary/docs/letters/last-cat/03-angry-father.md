| Field | Value |
|---|---|

| Status | Canon |
| Author | An angry father |
| Recipient | Dear little one / the Last Cat |
| Tone | Bitter, exhausted, defeated |

| Guardian / Attribute Mapping | Hidden cats — despair, concealment, and false finality |
| Best Star Reactions | Kaelia, Nyxari |
| Gameplay Use | Makes the player question whether the cats are dead, hidden, or unreachable in normal space. |

## Letter Text

Dear little one,

You cannot find this place because it is not anywhere.

The Stars know the way. That is enough.

There are no more cats left.

We searched.

We hoped.

We buried that hope years ago.

This is the only solution.

Stop looking.

~ An angry father

## Developer Notes

This should feel harsh but not villainous: a parent trying to protect a hiding place by killing hope.
