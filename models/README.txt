Put OpenWakeWord custom model files here if you want the launcher to start OpenWakeWord in auto mode.

Expected names used by scripts/openwakeword_server.py:
  elusiaa_custom.tflite
  kaelia_custom.tflite
  maera_custom.tflite
  khavia_custom.tflite
  auerlis_custom.tflite
  nyxari_custom.tflite

You can also set OWW_MODEL_DIR to another folder.
