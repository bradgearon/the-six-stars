# Controls and Combat System

## Controller map

| Input | Action |
|---|---|
| X | Jump |
| Square | Claw / light attack |
| Triangle | Sword attack after unlock |
| Circle | Roll / dodge |
| L1 | Parry |
| Hold R1 | Augmented claw or sword attack |
| L2 + Square/Triangle/X/Circle | Four ability slots |
| R2 + Square/Triangle/X/Circle | Four ability slots |

## Ability-slot progression

The eight-slot system is the endgame build canvas. It should not be available at full depth from the beginning.

1. **Opening:** one active ability from one equipped Star.
2. **Early-mid:** two Stars equipped, still limited in active depth.
3. **Post-soul sword:** no-mana versions start unlocking through attunement.
4. **Late game:** full eight slots for astral versions and remix builds.
5. **Rewrite/endgame:** only fully learned astral versions are guaranteed in hostile paths.

## Combat feel

Combat should feel like a graceful cat action game with fighting-game rhythm and action RPG spectacle. The player should be able to:

- start with claw pressure;
- cancel or branch into sword attacks;
- parry precise enemy strikes;
- use augmented attacks as finishers;
- weave Star projectiles into melee strings;
- enter Astral Expression Mode for heightened flow.

## Mana, Stardust, and Astral Expression

- **Mana:** borrowed Star/angel power.
- **Stardust:** generated by the Last Cat through action.
- **Astral Expression Mode:** triggered when stardust is full; reduces Stardust costs and causes attacks to generate Mana.
- **No-mana abilities:** learned by attuning to Star powers until the cat can perform the miracle without borrowing magic.

## Design requirement

Every Star ability must have a Mana version and a Stardust/no-mana version. The effect can be the same at first, but late-game astral versions should feel freer, more personal, and more ancient.
