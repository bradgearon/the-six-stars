# Area Index

The cave network is large enough to support a 35–45 hour single-player campaign. It should not be described as only “the Virethorn Caves.” Virethorn is the first major section, not the whole world.

| Order | Area | Core Identity | Major Content |
|---|---|---|---|
| 1 | [Virethorn Section / First Sanctuary](lower-caves-virethorn-sanctuary.md) | Poison water, dark rocky caves, first goblin-harpy settlement. | Elusiaa, Kaelia, slime abuse, first AI wisdom tests. |
| 2 | [Upper Caves / Highroot Waterworks](upper-caves-highroot-waterworks.md) | More vertical/action, high-tech cave traces, slime pressure. | Large slime encounters, movement challenges, bridge toward deeper caves. |
| 3 | [Bone Caves / Marrow Ossuary](bone-caves-marrow-ossuary.md) | Flesh, bones, marrow, skull walls, bridge-building. | Maera, Khavia, Bone Bloom, Marrowlily. |
| 4 | [Astral Caverns / Leviathan Road](astral-caverns-leviathan-road.md) | Crystals, sand, Astral Sea, guardians, letters. | Nyxari/Auerlis material, crystal hunt, Leviathan, astral swords. |
| Special | [Astral Book Room](astral-book-room.md) | Save/journal/memory sanctuary. | Astral Book, Elusiaa guide quote, letter processing. |
