# Astral Book Room

## Function

The Astral Book Room is a save/memory sanctuary and one of the most important readable visual spaces in the game. It visually communicates that the player's journey is being written, remembered, and called back by the Astral Stream.

## Key Quote

> “The astral book remembers your journey. Write, and it will call you back.”

## Visual Notes

The updated `levels and temples.docx` page 1 shows an **Astral Book Room tileset** with:

- Walls and background bookshelves.
- Floors and platforms.
- An Astral Book and pedestal.
- Book effects / save magic.
- UI save indicators.
- Statues and ornaments.
- Lighting and atmosphere assets.
- Cat companions.
- A gameplay mockup with Elusiaa standing beside the Last Cat at the glowing book.

## Design Use

- Save point.
- Letter reading/return interface.
- AI companion conversation anchor.
- Recap/journal updates.
- Memory compression before export to Rescue the Stars.
- Safe-ish space, but not always free from subtle music distortion.

## Mood

Warm blue-purple starlight, cave shelves, luminous ancient machinery, and soft Elusiaa presence. It should feel like the player's story is being protected by the Stream.
