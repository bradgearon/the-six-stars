# Star Writing Methods: Semantic Collision + Verb and Noun Displacement

The writing bench chooses one creative method at the start of every batch.

## Weighted method selection

```json
"WritingMethods": {
  "SemanticCollisionWeight": 0.7,
  "VerbNounDisplacementWeight": 0.3
}
```

The values are relative weights. With the defaults, approximately 70% of batches use semantic collision and 30% use verb and noun displacement. Either weight can be set to zero to disable that method without changing code.

Environment overrides:

- `SIX_STARS_WRITING_SEMANTIC_COLLISION_WEIGHT`
- `SIX_STARS_WRITING_VERB_NOUN_DISPLACEMENT_WEIGHT`

## Semantic collision

This is the existing process:

1. Privately select five pairs of substantially unrelated words.
2. Write one concise finished piece from each pair.
3. Run the configured number of review/improvement passes.
4. Run the normal 27-score persistence review.

Semantic collision keeps its existing optional mixed 100-word seed list and word-repetition history.

## Verb and noun displacement

Pass one is also two staged:

1. The Star privately thinks of five distinct object nouns and exactly three ordinary actions for each object.
2. For each object, she chooses one normal action, replaces it with an unexpected verb/action, and completes the resulting statement into something beautiful, deep, funny, interesting, exciting, or otherwise memorable.

### Noun diversity

The displacement noun-selection step now receives its own 100-word seed list containing **nouns only**. It is generated by the same random-word provider used by semantic collision, but it requests the noun dictionary for all 100 entries.

The writing-notes state now stores:

- `RecentGeneratedNouns`: the most recent 50 nouns selected by the displacement noun/object setup step, newest batch first;
- `GeneratedNounUsageCounts`: cumulative counts for every displacement noun selected from this point forward.

Every new noun-selection prompt is given:

- the 100 optional seed nouns;
- the 50 most recently selected nouns;
- the top 100 most-used selected nouns with their use counts.

The prompt asks the Star to prefer fresh / less-used nouns when quality is otherwise comparable. Nouns are recorded immediately after the initial noun/object setup succeeds, before any later writing-improvement pass changes a candidate.

### Verb uniqueness

Verb duplication is now blocked at both prompt and runtime-validation levels:

- all 15 ordinary actions across the five objects must be distinct;
- all five displaced verbs must be distinct from one another;
- a displaced verb may not duplicate any of the 15 ordinary-action verbs;
- an iterative improvement that would duplicate another current displaced verb is rejected;
- the initial noun/action step and the composition step each get one corrective retry if the model violates the uniqueness contract.

The second response records the noun, the ordinary verb that was displaced, the new displaced verb, and the finished writing. Internally the candidate's two tracked words are the noun plus displaced verb so it can use the existing review, history, scoring, and persistence pipeline.

Passes two and later use a displacement-specific review prompt. A proposed replacement may change the noun, the displaced verb, or both, then rewrite the completion. It returns the same old/new 0-100 scores as semantic collision. The runtime accepts only a strictly higher-scoring replacement and will not accept a replacement whose displaced verb duplicates another current candidate.

The displacement cycle's 100 noun seeds remain available to later improvement passes as optional **noun** ideas only. They are no longer presented as verb suggestions in the composition step.

## Persistence and diagnostics

Writing notes are version 9. New batches, history items, persisted writings, and the all-Star JSONL statement log continue to record `WritingMethod`, allowing quality and persistence comparisons between:

- `semantic-collision`
- `verb-noun-displacement`

The latest notes state also records `LatestWritingMethod`.
