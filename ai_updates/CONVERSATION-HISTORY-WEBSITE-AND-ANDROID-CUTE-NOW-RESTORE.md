# Conversation History Website and Android Cute Now Restore

- Restored a desktop **Open Conversation History Website** button in Quick Actions.
- The desktop app builds a readable local HTML page containing up to 500 newest saved turns for each of the six Stars and opens it in the default browser.
- Restored a girlfriend-settings **Cute Now** button on Android.
- `Cute Now` enables cute mode and immediately marks the current girlfriend hourly state as active instead of waiting for the next deterministic hourly roll.
- Added the `ActivateCuteModeNow` mobile bridge command and state event flow.
